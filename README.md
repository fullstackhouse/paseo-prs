# paseo-prs

A [Paseo](https://paseo.sh) plugin: the pull requests for an agent's branch as pills in its composer (`#123 · 2 failing`), with a **Create PR** button when there is none.

See [OVERVIEW.md](./OVERVIEW.md) for behaviour and limits, [AGENTS.md](./AGENTS.md) for the code.

```bash
npm install && npm run typecheck && npm test
paseo plugin install "$PWD"
```
